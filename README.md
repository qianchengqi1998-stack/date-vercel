# DATE

一个适合朋友或两人见面邀约的手机端网页。邀请对象先选择是否同意；同意后再选择活动、日期、时间和地点，并可把最终安排页面分享回邀请人。

## 本地开发

需要 Node.js 22 或更高版本：

```bash
npm install
npm run dev
```
